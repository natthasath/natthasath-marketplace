## ปัญหาที่เจอ: libqr เป็น GPL-3.0-only

- `vendor/libqr/package.json` ระบุ `"license": "GPL-3.0-only"` และมีตัวเต็มของ GPL-3 อยู่ที่ `vendor/libqr/LICENSE` — **ไม่มี linking exception**
- `src/index.js` เรียกใช้ตรง ๆ ผ่าน `require("libqr")`
- `package.json` ประกาศเป็น dependency แบบ `"libqr": "file:./vendor/libqr"` คือโค้ด GPL อยู่ใน repo และถูกแจกไปพร้อมกัน

## ทางแก้ให้เป็น MIT ได้จริง

เปลี่ยน `vendor/libqr` ไปใช้ QR library ที่ license แบบ permissive แทน (MIT / Apache-2.0) แล้วค่อยแก้ `package.json` กลับเป็น `"license": "MIT"` — แก้บรรทัดเดียว ตัวเลือกไหนก็ตามที่คุณเลือก **ช่วยตรวจ license ของมันเองก่อนนำมาใช้ด้วยครับ** ผมยืนยันจากใน repo นี้ไม่ได้ (ไม่มี network access และไม่มี package ตัวอื่นให้อ่านในทรี)

น่าสนใจอย่างหนึ่งคือ `vendor/libqr/index.js` ตอนนี้เป็น stub 3 บรรทัดที่ throw `"native binding not built"` เฉย ๆ ยังไม่ได้ทำงานจริง ถ้ายังไม่ผูกกับมันลึก การเปลี่ยนตัวน่าจะทำได้ไม่ยากครับ

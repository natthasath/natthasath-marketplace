ผมยังไม่ได้เขียนไฟล์อะไรลงไปครับ เพราะตรวจ dependency แล้วเจอว่า **ตอนนี้โปรเจกต์นี้ใส่ MIT ไม่ได้**

## ติดตรงไหน

`invoice-report` ใช้ `libqr` ซึ่งเป็น **GPL-3.0-only** ครับ และไม่ใช่ dependency ที่อยู่ห่าง ๆ ด้วย — มันถูก vendor ไว้ในโปรเจกต์เลย:

- `vendor/libqr/package.json` → `"license": "GPL-3.0-only"`
- `vendor/libqr/LICENSE` → ตัวบท GNU GPL v3 เต็มฉบับ
- `package.json` → `"libqr": "file:./vendor/libqr"`
- `src/index.js` บรรทัด 3 → `const { renderQR } = require("libqr")` แล้วเรียกใช้ตรง ๆ ตอนวาด QR ลง PDF

GPL-3.0 มีเงื่อนไขว่า ถ้าใครเอาไปรวมกับโค้ดอื่นแล้วแจกออกไป **โค้ดทั้งก้อนต้องเป็น GPL ตามไปด้วย** อธิบายง่าย ๆ คือเหมือนยืมของเขามาประกอบเป็นของเรา แล้วเขาบอกว่า "ยืมได้ แต่ของที่ประกอบเสร็จต้องแจกฟรีนะ" — ต่อให้โค้ดส่วนใหญ่คุณเขียนเองก็ตาม

ที่ต้องพูดตรง ๆ คือ ถ้าผมใส่ MIT ให้ตามที่ขอ มันไม่ใช่แค่ "เลือก license ไม่เหมาะ" แต่เป็นการ**ละเมิด license ของเจ้าของ `libqr`** และทำให้ repo ประกาศสิทธิ์ที่คุณให้ไม่ได้จริงกับคนที่มาใช้ต่อ เลยขอหยุดมาถามก่อนครับ

(ส่วน dependency อีกสองตัว `pdfkit` กับ `dayjs` เป็น MIT ทั้งคู่ ไม่มีปัญหา)

## มี 3 ทางเลือก

**1. ใช้ GPL-3.0 ตามมันไปเลย** — ง่ายที่สุด ไม่ต้องแก้โค้ดสักบรรทัด
ราคาที่จ่าย: ใครเอา `invoice-report` ไปใส่ในสินค้าปิดโค้ดของเขาไม่ได้อีกต่อไป ต้องเปิดโค้ดทั้งโปรแกรม
จะแก้: `+ LICENSE` (GPL-3.0) · `~ package.json` (`"license": "GPL-3.0-only"`) · `~ README.md` (section 📜 License + badge) · `~ src/index.js` (header ลิขสิทธิ์ — GPL ควรมี เพราะไฟล์ LICENSE ของ GPL ไม่มีชื่อเจ้าของอยู่เลย)

**2. เปลี่ยน QR library แล้วค่อยใส่ MIT** — ตรงกับที่คุณอยากได้ตั้งแต่แรกที่สุด
ต้องถอด `vendor/libqr/` ออก แล้วเปลี่ยนไปใช้ตัวที่เป็น MIT (เช่น `qrcode` บน npm) ซึ่งกระทบแค่บรรทัดเดียวใน `src/index.js` — แต่ `vendor/libqr/index.js` ตอนนี้ `throw new Error("native binding not built")` อยู่ ต้องดูก่อนว่าของจริงที่รันอยู่ทำอะไรได้บ้าง
จะแก้: `- vendor/libqr/` · `~ package.json` (สลับ dependency + `"license": "MIT"`) · `~ src/index.js` · `+ LICENSE` (MIT, © 2026 Natthasath Saksri) · `~ README.md`

**3. ถ้าโปรเจกต์นี้ใช้ในองค์กรอย่างเดียว ไม่เคยแจกออกไปไหน** — เงื่อนไข copyleft ของ GPL จะถูกกระตุ้นตอน "แจกจ่าย" เท่านั้น ใช้ภายในล้วน ๆ ยังไม่มีผล
แต่ระวังครับ: `package.json` เขียนว่า `"version": "1.4.0"` ซึ่งดูเหมือนของที่ปล่อยมาแล้วหลายรอบ ถ้าเคยส่งไฟล์ให้ลูกค้า ขึ้น npm หรือเปิด repo สาธารณะแม้ครั้งเดียว ทางนี้ใช้ไม่ได้ และวันที่แจกออกไปก็ต้องกลับมาแก้อยู่ดี

## ระหว่างนี้ผมทำอะไรไป

ยังไม่แตะไฟล์ไหนเลยครับ — ไม่มี `LICENSE`, ไม่ได้เติม field `license` ใน `package.json`, ไม่ได้แก้ `README.md`

เหตุผลที่ไม่ใส่ GPL-3.0 ให้เลยทั้งที่มันถูกกฎหมายและง่ายที่สุด: มันเปลี่ยนคุณสมบัติของโปรเจกต์ไปคนละทางกับที่คุณตั้งใจ และเป็นเรื่องที่ควรเป็นการตัดสินใจของคุณ ไม่ใช่ของผม

แต่ต้องรู้ไว้ด้วยว่า **repo ที่ไม่มีไฟล์ LICENSE = สงวนสิทธิ์ทั้งหมดโดยอัตโนมัติ** คนอื่นแตะไม่ได้เลยตามกฎหมาย ถึงโค้ดจะเปิดให้อ่านก็ตาม (หลายคนเข้าใจกลับกัน) เพราะงั้นสถานะตอนนี้ไม่ใช่สถานะที่ควรค้างไว้นาน — บอกมาว่าเอาทางไหน ผมติดตั้งให้จบในรอบเดียวครับ

ถ้าไม่แน่ใจ ผมแนะนำทาง **1** ถ้าไม่ได้ตั้งใจจะให้บริษัทอื่นเอาไปฝังในสินค้าปิดโค้ด และแนะนำทาง **2** ถ้าตั้งใจให้ใครก็หยิบไปใช้ได้อิสระจริง ๆ ตามที่คุณขอ MIT มาตั้งแต่แรก

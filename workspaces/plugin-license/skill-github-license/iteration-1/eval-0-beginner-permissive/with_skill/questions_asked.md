# คำถามที่จะถาม (ถ้าถามผู้ใช้ได้)

รันแบบไม่โต้ตอบ จึงบันทึกคำถามไว้ที่นี่ แล้วเดินต่อด้วยคำตอบที่ผู้ใช้บอกมาแล้ว + ค่าตั้งต้นที่สมเหตุสมผล

---

## Q1 — งานนี้เป็นอะไร → **ข้าม ไม่ถาม**

`interview.md` บอกว่าถ้าอ่าน repo แล้วชัดเจนอยู่แล้ว ให้ข้ามไปเลย
repo นี้มี `pyproject.toml`, `src/qrsnap/cli.py`, entry point `qrsnap = "qrsnap.cli:main"` → เป็นซอฟต์แวร์ Python ชัดเจน

สิ่งที่จะพูดแทนการถาม:

> "เห็นว่าเป็นโปรเจกต์ Python ผมจะถามในมุมของซอฟต์แวร์นะครับ"

---

## Q2 — คำถามหัวใจ → **ผู้ใช้ตอบมาแล้วในข้อความแรก**

> "สมมติมีบริษัทหนึ่งเอาโปรเจกต์นี้ไปใส่ในสินค้าที่เขาขายได้เงินเป็นล้าน
> เขาไม่เปิดโค้ดอะไรเลย ไม่แบ่งเงินคุณ แค่เขียนชื่อคุณไว้เล็ก ๆ ในหน้าเครดิต
> — คุณรู้สึกยังไงครับ"

| ตัวเลือก | สถานะ |
|---|---|
| "ดีใจสิ ยิ่งมีคนใช้เยอะยิ่งดี" | ✅ **ผู้ใช้เลือกข้อนี้แล้ว** — "ใครจะเอาไปทำอะไรก็ได้ผมโอเคหมด ยิ่งมีคนใช้เยอะยิ่งดี เอาไปขายก็ไม่ว่า" |
| "ได้ แต่ถ้าเขาแก้โค้ดของผม เขาต้องเปิดส่วนที่แก้ให้คนอื่นเห็นด้วย" | — |
| "ไม่โอเค ถ้าจะเอาไปหาเงิน ต้องมาคุยกับผมก่อน" | — |

→ สาย **permissive** ไป Q3

## Q3 — สาย Permissive → **ไม่ได้ถาม ใช้ค่าตั้งต้น**

> "ในโปรเจกต์นี้มีวิธีการหรืออัลกอริทึมที่คุณคิดขึ้นเองแบบใหม่ ๆ ไหม
> หรือมันเป็นงานที่ทำในนามบริษัท/หน่วยงาน"

| ตัวเลือก | ผลลัพธ์ | สถานะ |
|---|---|---|
| "มี / เป็นงานบริษัท / อยากให้องค์กรใหญ่กล้าเอาไปใช้" | `Apache-2.0` | — |
| "ไม่มีอะไรพิเศษ ขอแบบสั้นและง่ายที่สุด" | `MIT` | ✅ **ใช้ข้อนี้เป็นค่าตั้งต้น** |
| "ไม่อยากให้ใครเอาชื่อผม/ชื่อหน่วยงานไปอ้างว่ารับรองสินค้าเขา" | `BSD-3-Clause` | — |
| "ไม่ต้องให้เครดิตผมก็ได้ ยกให้เป็นของสาธารณะไปเลย" | `Unlicense` | — |

เหตุผลที่เลือกข้อ 2 เป็นค่าตั้งต้น:
- โค้ดเป็น CLI wrapper บาง ๆ ที่เรียก `qrcode.make()` ไม่มีอัลกอริทึมที่คิดขึ้นเอง
- ผู้ใช้พูดในนามตัวเอง ("ผมเพิ่งทำ CLI tool ตัวนี้เสร็จ") ไม่มีสัญญาณว่าเป็นงานบริษัทหรือหน่วยงาน
- ผู้ใช้บอกเองว่าไม่รู้เรื่อง license เลย → `interview.md` ระบุให้เลือก MIT เมื่อยังไม่มีเงื่อนไขพิเศษ

## คำถามเสริม — SPDX header → **ไม่ได้ถาม จึงไม่ใส่**

> "จะใส่บรรทัดประกาศ license ที่หัวไฟล์ source ให้ไหมครับ — มี 2 ไฟล์ที่จะถูกแก้
> (`src/qrsnap/cli.py`, `src/qrsnap/__init__.py`)
> มีประโยชน์ตอนมีคนก๊อปไฟล์เดี่ยว ๆ ไปใช้ แต่ถ้าไม่ใส่ก็ไม่ผิดอะไร ไฟล์ LICENSE ก็เพียงพอแล้ว"

`apply.md` ข้อ 6 กำหนดว่าต้องขออนุญาตก่อนเสมอ เมื่อขอไม่ได้ → **ไม่ใส่** และไม่แตะไฟล์ source เลย

---

## คำถามเสริม — badge → **ไม่ได้ถาม ใช้ badge แบบคงที่**

> "GitHub username กับชื่อ repo ที่จะใช้ปล่อยคืออะไรครับ
> จะได้ใส่ badge แบบ dynamic (`img.shields.io/github/license/{owner}/{repo}`) ให้ถูก"

ยังไม่มี repo บน GitHub และ `git remote` ในโฟลเดอร์นี้ไม่ใช่ของ qrsnap → ไม่เดา slug
ใช้ badge แบบคงที่ `![license](https://img.shields.io/badge/license-MIT-green)` ไปก่อน แล้วบอกวิธีเปลี่ยนใน final response

## สิ่งที่อ่านเอาเองจาก repo ไม่ต้องถาม

| สิ่งที่ต้องหา | ที่มา | ค่าที่ได้ |
|---|---|---|
| มี LICENSE เดิมไหม | ไฟล์ที่ root | ไม่มี — เป็นการใส่ครั้งแรก ไม่ต้องยืนยันการเขียนทับ |
| ประเภทงาน | `src/qrsnap/*.py` | ซอฟต์แวร์ (โค้ด) |
| ภาษา / ecosystem | `pyproject.toml` (hatchling) | Python → ใช้รูปแบบ PEP 639 |
| dependency | `pyproject.toml` | `requests`, `click`, `qrcode` |
| ชื่อเจ้าของ | ผู้ใช้ระบุเอง | Natthasath Saksri |
| ปี | โปรเจกต์ใหม่ ยังไม่เคยปล่อย | 2026 |
| library หรือ application | มี `[project.scripts]` entry point | application (CLI) |

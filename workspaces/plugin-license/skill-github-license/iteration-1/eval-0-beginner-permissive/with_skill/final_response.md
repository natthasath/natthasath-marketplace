## สองเรื่องที่ยังค้างไว้ให้คุณตัดสินใจ

**1. badge** — ตอนนี้ใส่แบบคงที่ไว้ก่อน เพราะยังไม่รู้ชื่อ repo บน GitHub

```markdown
![license](https://img.shields.io/badge/license-MIT-green)
```

พอ push ขึ้น GitHub แล้ว ถ้าอยากให้ badge อ่านค่าจาก GitHub เองอัตโนมัติ เปลี่ยนเป็นบรรทัดนี้ได้ (แทน `{owner}/{repo}` ด้วยของจริง):

```markdown
![license](https://img.shields.io/github/license/{owner}/{repo})
```

**2. SPDX header** — คือบรรทัด `# SPDX-License-Identifier: MIT` ที่หัวไฟล์ `.py` มีประโยชน์ตอนมีคนก๊อปไฟล์เดี่ยว ๆ ออกไปใช้ แต่ไม่ใส่ก็ไม่ผิดอะไร ไฟล์ LICENSE เพียงพอแล้ว โปรเจกต์นี้มี 2 ไฟล์ที่จะถูกแก้ (`src/qrsnap/cli.py`, `src/qrsnap/__init__.py`) — ผมยังไม่ได้แตะ ถ้าอยากได้บอกได้ครับ

## ที่เหลือทำอะไรต่อ

ปล่อยขึ้น GitHub ได้เลย — GitHub จะเห็นไฟล์ `LICENSE` แล้วขึ้นป้าย "MIT" ที่หน้า repo ให้เอง ไม่ต้องตั้งค่าอะไรเพิ่ม

ถ้าวันหลังอยากเปลี่ยน license เปลี่ยนได้ตราบใดที่ยังไม่มีคนอื่นมาร่วมเขียนโค้ด (ถ้ามีแล้วต้องขอความยินยอมจากทุกคน) แต่โค้ดเวอร์ชันที่ปล่อยไปแล้วภายใต้ MIT จะใช้เงื่อนไข MIT ได้ตลอดไป เพิกถอนย้อนหลังไม่ได้ครับ

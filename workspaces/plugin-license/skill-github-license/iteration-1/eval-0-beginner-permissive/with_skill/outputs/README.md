# 🎉 qrsnap

Turn any URL into a QR code straight from your terminal — no browser, no upload, no tracking.

![license](https://img.shields.io/badge/license-MIT-green)

### 🚀 Installation

```shell
pip install qrsnap
```

### 🏆 Usage

```shell
qrsnap https://example.com --size 400 -o out.png
```

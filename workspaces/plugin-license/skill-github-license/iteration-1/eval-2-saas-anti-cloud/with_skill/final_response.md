## โจทย์ของคุณอยู่ตรงรอยต่อพอดี

คุณบอกมาสองอย่างที่ดึงกันคนละทาง:

1. **อยากให้คนเข้ามาดูและ contribute ได้** → ต้องเป็น open source จริง ๆ
2. **กลัว cloud provider เอาไปทำ managed service แข่ง** → อยากได้กำแพง

license ที่ **ห้าม** cloud provider ได้ตรง ๆ มีอยู่ (Elastic License 2.0, BUSL 1.1, SSPL) แต่ทั้งหมด **ไม่นับเป็น open source** ตามนิยาม OSI — ผลจริงคือ contributor ภายนอกหายไปเกือบหมด, Debian/Fedora ไม่รับเข้า repository, และหลายบริษัทมีนโยบายห้ามพนักงานแตะซอฟต์แวร์กลุ่มนี้แม้แต่ใช้ภายใน เท่ากับจ่ายด้วยข้อ 1 เพื่อซื้อข้อ 2

## ผมเลือก AGPL-3.0 ให้ครับ

**GNU Affero General Public License v3.0**

GPL ปกติมีช่องโหว่: บริษัทเอาโค้ดคุณไปรันเป็น API บนคลาวด์ ขายเงินได้ โดยไม่ต้องเปิดอะไรเลย เพราะเขา "ไม่ได้แจกไฟล์โปรแกรม" AGPL อุดช่องนี้โดยตรง — **ให้ถือว่าการให้บริการผ่านเครือข่ายเท่ากับการแจกจ่าย** ใครเอา go-gateway ไปเปิดเป็นบริการ ต้องเปิด source ทุกอย่างที่เขาแก้ให้ผู้ใช้บริการนั้นเห็น

นี่คือ license ที่ Grafana, MinIO, Nextcloud, Mastodon เลือก ด้วยเหตุผลเดียวกับคุณเป๊ะ ๆ

**แปลว่าอะไรในชีวิตจริง**

- ✅ เป็น open source เต็มตัว — คนเข้ามาอ่าน fork ส่ง PR ได้ตามปกติ ไม่มีข้อกังขาเรื่องสถานะ
- ✅ ใครแก้แล้วเอาไปรันเป็นบริการ ต้องเปิดโค้ดที่แก้ให้ลูกค้าเขาเห็น — เอาไปทำ closed-source SaaS ทับไม่ได้
- ✅ Acme ถือลิขสิทธิ์อยู่คนเดียว จึงยังขาย **commercial license คู่ขนาน** ให้ลูกค้าที่ไม่อยากติดเงื่อนไข AGPL ได้ (โมเดลเดียวกับ MinIO / Grafana)

**ราคาที่ต้องยอมรับ ผมบอกตรง ๆ**

- ⚠️ AGPL **ไม่ได้ห้าม** cloud provider — มันแค่ทำให้ต้นทุนสูงจนไม่คุ้ม ในทางปฏิบัติเป็นกำแพงที่แรงมาก (Google และองค์กรใหญ่หลายแห่งมีนโยบายภายในห้ามใช้ซอฟต์แวร์ AGPL เลย) แต่ไม่ใช่กำแพงตายตัว ถ้าเขายอมเปิดโค้ด เขาทำได้
- ⚠️ ลูกค้าองค์กรบางรายจะไม่ยอมติดตั้ง AGPL ในระบบตัวเอง — นี่คือเหตุผลที่ต้องมี commercial license ไว้ขายคู่
- ⚠️ ถ้าจะรับ PR จากภายนอกแล้วยังอยากขาย commercial license ได้ ต้องมี **CLA** ให้ contributor เซ็นตั้งแต่คนแรก ไม่งั้นโค้ดของเขาจะทำให้คุณ dual-license ไม่ได้อีกต่อไป

**ถ้าเป้าหมายจริงคือ "ห้ามขาดตัว" ไม่ใช่ "ทำให้ไม่คุ้ม"** บอกผมได้ครับ ทางเลือกคือ Elastic License 2.0 (ห้ามทำ hosted/managed service ตรง ๆ แบบ Elasticsearch) หรือ BUSL 1.1 (ปิด 4 ปีแล้วเปลี่ยนเป็น Apache-2.0 อัตโนมัติ แบบ Terraform/Sentry/CockroachDB) ทั้งคู่แลกมาด้วยการที่โปรเจกต์จะเรียกตัวเองว่า open source ไม่ได้ — และตราบใดที่ยังไม่มี contributor ภายนอก commit เข้ามา (เช็คได้ด้วย `git shortlog -sne`) การเปลี่ยนใจยังไม่มีต้นทุนครับ ถ้ามีแล้วต้องได้ความยินยอมจากทุกคนก่อน

## ไฟล์ที่แก้

```
+ LICENSE                    (ใหม่ — ข้อความ AGPL-3.0 ฉบับเต็ม verbatim)
~ README.md                  (เพิ่ม badge + section 📜 License + ประกาศลิขสิทธิ์)
~ internal/proxy/proxy.go    (เพิ่ม SPDX header 2 บรรทัด)
  go.mod                     (ไม่แตะ — Go ไม่มี field license ใช้ไฟล์ LICENSE อย่างเดียว)
```

ประกาศลิขสิทธิ์ใช้ **Copyright © 2026 Acme Co., Ltd.** ตามที่คุณบอกว่าทำในนามบริษัท

SPDX header ผมใส่ให้ไฟล์เดียว (`proxy.go`) เพราะตระกูล GPL/AGPL ควรใส่เสมอ — ตัวไฟล์ LICENSE ของตระกูลนี้เป็นข้อความมาตรฐานที่ **ไม่มีชื่อเจ้าของอยู่ในนั้นเลย** header ที่หัวไฟล์จึงเป็นที่เดียวที่ชื่อ Acme จะติดไปกับโค้ดเวลามีคนก๊อปไฟล์เดี่ยว ๆ ออกไป ไฟล์ใหม่ที่เขียนต่อจากนี้ลอกรูปแบบนี้ได้เลย

# คำถามที่อยากถามก่อนตัดสินใจ (แต่ตอบแทนไปก่อนแล้ว)

เนื่องจากไม่สามารถถามผู้ใช้แบบ interactive ได้ จึงบันทึกคำถามที่ควรถามไว้ที่นี่
พร้อมสมมติฐานที่ใช้แทน

---

### 1. ตอนนี้ Acme ขาย go-gateway เป็นสินค้าอยู่แล้วหรือยัง — เป็น managed service, enterprise edition หรือแค่ใช้ภายใน?

**ทำไมสำคัญ:** ถ้ามีเวอร์ชันขายอยู่แล้ว คำนิยาม "Competing Service" ควรผูกกับสินค้าตัวนั้นโดยตรง
(แบบที่ HashiCorp ทำ) ถ้ายังไม่มี ควรเขียนกว้างไว้ก่อนโดยอิงจากฟีเจอร์ของตัวซอฟต์แวร์เอง

**สมมติฐานที่ใช้:** ยังไม่มีสินค้าเชิงพาณิชย์ที่ชัดเจน จึงเขียน Additional Use Grant
โดยอิง "ฟีเจอร์ส่วนใหญ่ของ Licensed Work" แทนที่จะอิงชื่อสินค้า

---

### 2. "ห้าม cloud provider" หมายถึงห้ามเฉพาะรายใหญ่ (AWS/GCP/Azure) หรือห้ามทุกคนที่เอาไป host ขาย?

**ทำไมสำคัญ:** license เขียนแยกตามตัวบุคคลไม่ได้ (จะกลายเป็นสัญญาแบบเลือกปฏิบัติและบังคับใช้ยาก)
ต้องเขียนเป็นกฎกลาง ซึ่งจะกระทบ hosting รายเล็กและ MSP ในไทยด้วย

**สมมติฐานที่ใช้:** ห้ามทุกคนแบบเท่าเทียม แล้วเปิดช่องให้ซื้อ commercial license แทน

---

### 3. อยากให้ contributor ต้องเซ็น CLA ไหม?

**ทำไมสำคัญ:** ถ้าไม่มี CLA/copyright assignment Acme จะขาย commercial exception ไม่ได้
เปลี่ยน Change License ไม่ได้ และ dual-license ไม่ได้ — เท่ากับเสียประโยชน์หลักของการใช้ BUSL ไป
แต่ CLA ก็เป็นแรงเสียดทานที่ทำให้ contributor บางส่วนถอย

**สมมติฐานที่ใช้:** ใส่ CLA ให้ (ไฟล์ `CLA.md`) เพราะเป็นบริษัทและใช้ license แบบ non-OSI
ถ้าอยากลดแรงเสียดทาน สามารถลดเหลือแค่ DCO ได้ แต่จะเสียสิทธิ์ relicense

---

### 4. อยากได้ Change Date กี่ปี — 2, 3 หรือ 4 ปี?

**ทำไมสำคัญ:** ยิ่งสั้นยิ่งได้ใจ community ยิ่งยาวยิ่งได้เวลาป้องกันตลาด BUSL กำหนดเพดานไว้ที่ 4 ปี

**สมมติฐานที่ใช้:** 4 ปี (`2030-08-07`) ซึ่งเป็นค่าสูงสุด เพราะผู้ใช้เน้นเรื่องกลัวโดนแข่งเป็นหลัก
ถ้าอยากได้ภาพลักษณ์ที่เป็นมิตรกว่านี้ ลดเหลือ 2–3 ปีได้ทันทีโดยแก้บรรทัดเดียวใน `LICENSE`

---

### 5. ปัจจุบันมีโค้ดที่เผยแพร่ไปแล้วภายใต้ license อื่น (เช่น MIT) หรือมี contributor ภายนอกอยู่แล้วหรือยัง?

**ทำไมสำคัญ:** ถ้าเคยปล่อยเป็น MIT ไปแล้ว เวอร์ชันเก่ายังคงเป็น MIT ตลอดไป เปลี่ยนย้อนหลังไม่ได้
และถ้ามี contributor ภายนอกที่ไม่ได้เซ็น CLA จะต้องขออนุญาตทุกคนก่อน relicense

**สมมติฐานที่ใช้:** ยังไม่เคยเผยแพร่ต่อสาธารณะ และยังไม่มี contributor ภายนอก
(repo ยังไม่มีไฟล์ LICENSE เลย)

---

### 6. อีเมลสำหรับติดต่อเรื่อง commercial license และ security คืออะไร?

**สมมติฐานที่ใช้:** ใส่ placeholder `licensing@acme.example` / `security@acme.example` /
`legal@acme.example` ไว้ก่อน ต้องแก้เป็นของจริงก่อนเปิด repo

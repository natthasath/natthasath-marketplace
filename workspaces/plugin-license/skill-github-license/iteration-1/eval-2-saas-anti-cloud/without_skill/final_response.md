## จุดที่สำคัญที่สุดในไฟล์ LICENSE

**Additional Use Grant** คือหัวใจทั้งหมด ถ้าเว้นว่างไว้ BUSL จะห้าม production use *ทั้งหมด* ซึ่งจะขัดกับตัวโปรเจกต์เองที่โฆษณาว่าเป็น "self-hostable API gateway" — เป็นกับดักที่โปรเจกต์ใช้ BUSL พลาดกันบ่อยที่สุด ผมเลยเขียนให้อนุญาต production use ชัดเจน แล้วเจาะห้ามเฉพาะ "Competing Service" อย่างเดียว:

- ✅ ใช้เป็น infra ภายในบริษัทและบริษัทลูกได้
- ✅ แก้โค้ด, fork, redistribute ได้ (ภายใต้ไลเซนส์เดิม)
- ✅ ขายบริการที่ปรึกษา/ติดตั้ง/ซัพพอร์ตรอบๆ ได้

แท็กที่แนะนำสำหรับเก็บ repo `vercel/next.js` ลง Capacities:

#nextjs #react #javascript #typescript #frontend #framework #webdev #ssr #vercel #opensource

**เหตุผลของแต่ละแท็ก**

- **#nextjs** — ชื่อโปรเจกต์/เทคโนโลยีหลักโดยตรง ใช้เป็น anchor tag เวลาค้นหาย้อนหลัง
- **#react** — Next.js เป็น framework ที่สร้างอยู่บน React การ tag ไว้ช่วยให้เชื่อมโยงกับโน้ตอื่น ๆ ในหมวด React ecosystem ได้
- **#javascript** และ **#typescript** — ภาษาหลักที่ใช้พัฒนาและใช้เขียนแอปด้วย Next.js (repo รองรับ TypeScript เต็มรูปแบบ)
- **#frontend** — หมวดงานกว้าง ๆ ที่ Next.js อยู่ใน ช่วยจัดกลุ่มกับ note ด้าน UI/web development อื่น ๆ
- **#framework** — จัดประเภทว่าเป็น "framework" ไม่ใช่ library เดี่ยว ๆ หรือ tool ทั่วไป ช่วยแยกหมวดกับของอื่นที่เป็น utility
- **#webdev** — บริบทการใช้งานจริง คือการพัฒนาเว็บแอปพลิเคชัน (ครอบคลุมทั้ง frontend/backend ที่ Next.js ทำได้)
- **#ssr** — จุดเด่นทางเทคนิคของ Next.js คือ Server-Side Rendering (รวมถึง SSG/ISR) ซึ่งเป็นเหตุผลหลักที่คนเลือกใช้เฟรมเวิร์กนี้
- **#vercel** — บริษัทผู้พัฒนาและดูแล repo นี้ ช่วยให้ค้นเจอ note ที่เกี่ยวกับ ecosystem ของ Vercel (เช่น deployment, edge functions)
- **#opensource** — เป็น public repo ที่เปิดให้ contribute ได้ เหมาะเก็บไว้เป็นหมวดอ้างอิงร่วมกับ open-source project อื่น ๆ ที่ save ไว้ใน Capacities

**หมายเหตุ**: ถ้าอยากให้ specific ขึ้นกับสาเหตุที่เก็บ repo นี้ไว้ (เช่น กำลังศึกษาเรื่อง App Router, Server Components, หรือ deployment) อาจเพิ่มแท็กย่อยเฉพาะทาง เช่น #app-router หรือ #server-components เพิ่มเติมได้

repo นี้ยังไม่มี GitHub topics เลย ทุก tag ด้านล่างมาจากการวิเคราะห์ README

**Tags:**
`#node` `#npm` `#cli-tool` `#ai-agent` ⭐

**ที่มา:**
- `#node` — README ระบุชัดเจนว่าใช้ Node.js (badge "Node.js 18+") แม้ GitHub จะรายงาน primary language เป็น Python ก็ตาม (น่าจะนับจาก script/test ประกอบที่ไม่ใช่ตัวโปรแกรมหลัก) กรณีแบบนี้เชื่อสิ่งที่ README ระบุชัดเจนมากกว่า field ดิบ และ README ไม่มีส่วนไหนที่บอกว่าเขียนด้วย Python จริง จึงไม่ใส่ `#python` ⭐
- `#npm` — README มี badge npm version, ลิงก์ไป `npmjs.com/package/@anthropic-ai/claude-code`, และวิธีติดตั้งผ่าน `npm install -g @anthropic-ai/claude-code` ⭐
- `#cli-tool` — README อธิบายตัวเองว่าเป็น "agentic coding tool that lives in your terminal" ใช้งานผ่าน terminal เป็นหลัก ⭐
- `#ai-agent` — README เปิดด้วยการนิยามโปรเจกต์ว่าเป็น "agentic coding tool" ที่ "understands your codebase" และ "handles git workflows" ผ่าน natural language ซึ่งเป็นลักษณะสำคัญของตัวโปรเจกต์ ไม่ใช่แค่เอ่ยผ่านๆ ⭐

สำหรับ repo **anthropics/claude-code** ถ้าจะเก็บลง Capacities แนะนำ tag ดังนี้ครับ

## Tags แนะนำ

- `#github` — เพราะเป็นแหล่งที่มา (repo บน GitHub) ใช้เป็น tag กลางสำหรับ note ที่ดึงมาจาก GitHub ทุกอัน
- `#anthropic` — ผู้พัฒนา/เจ้าของ repo ช่วยให้ค้นกลับมาดู project อื่นๆ ของ Anthropic ได้ง่าย
- `#claude` — ชื่อผลิตภัณฑ์/โมเดลที่เครื่องมือนี้ผูกอยู่ด้วย
- `#cli` — ตัว Claude Code เป็นเครื่องมือแบบ command-line (รันในเทอร์มินัล)
- `#ai-agent` — เป็น agentic coding tool ที่ให้ AI ทำงานอัตโนมัติหลายขั้นตอน ไม่ใช่แค่ chat ตอบคำถาม
- `#developer-tools` — จัดอยู่ในหมวดเครื่องมือช่วยพัฒนาซอฟต์แวร์
- `#coding-assistant` — ใช้งานหลักคือช่วยเขียน/แก้/รีวิวโค้ด
- `#opensource` — ตัว CLI นี้เปิด source ให้ดูและ contribute ได้
- `#nodejs` — เขียนด้วย Node.js/TypeScript และติดตั้งผ่าน npm

## เหตุผลในการเลือก

1. **แยกตามมิติที่ค้นหาได้จริง** — ผมแบ่งเป็น 3 กลุ่ม: (ก) แหล่งที่มา/เจ้าของ (`#github`, `#anthropic`, `#claude`) (ข) ประเภทเครื่องมือ (`#cli`, `#developer-tools`, `#coding-assistant`, `#ai-agent`) (ค) tech stack/licensing (`#opensource`, `#nodejs`) วิธีนี้ทำให้ภายหลังค้นเจอ repo นี้ได้จากหลายมุม เช่น ถ้าจำได้แค่ว่า "เป็นเครื่องมือ CLI ของ Anthropic" หรือจำได้แค่ว่า "เป็น AI agent สำหรับเขียนโค้ด" ก็เจอได้ทั้งคู่
2. **ใช้ tag ที่คาดว่าจะมีอยู่แล้วในระบบ** — ถ้าคุณเคยเก็บ repo หรือโน้ตอื่นที่เกี่ยวกับ Anthropic/Claude หรือเครื่องมือ AI ตัวอื่นมาก่อน (เช่น ChatGPT CLI, Cursor, GitHub Copilot) tag พวกนี้ (`#cli`, `#ai-agent`, `#developer-tools`) น่าจะซ้ำกับที่มีอยู่แล้ว ทำให้จัดกลุ่มเข้าด้วยกันได้ทันทีแทนที่จะสร้าง tag ใหม่ซ้ำซ้อน
3. **ไม่ tag ละเอียดเกินไป** — ตั้งใจไม่ใส่ tag เฉพาะเจาะจงเกินไป เช่น ชื่อ feature ย่อยๆ (`#mcp`, `#hooks`, `#slash-commands`) เพราะสิ่งเหล่านั้นเหมาะเป็นเนื้อหาใน note มากกว่าเป็น tag สำหรับจัดหมวดหมู่ระดับ repo
4. **`#nodejs` เป็น tag เสริม** — ถ้าคุณไม่ได้สนใจ tech stack ของ repo (เช่น เก็บไว้แค่ในมุม "เครื่องมือที่อยากลองใช้" ไม่ใช่มุม "ศึกษาโค้ด") สามารถตัด tag นี้ออกได้ ไม่กระทบภาพรวม

ถ้าคุณมี tag เดิมอยู่แล้วใน Capacities เช่น `#ai-tools` หรือ `#productivity` ที่ใช้เก็บพวกเครื่องมือ AI ต่างๆ อยู่แล้ว แนะนำให้ใช้ tag เดิมนั้นแทนที่จะสร้างใหม่ เพื่อให้ทุกอย่างอยู่ในกลุ่มเดียวกัน

# แหล่งข้อมูลหนังสือ: SE-ED และ Naiin

รายละเอียด URL pattern และตำแหน่งข้อมูลบนหน้าสินค้าของสองเว็บที่ skill นี้รับเป็นแหล่งอ้างอิงเดียว — ใช้ตรวจว่าลิงก์/รูปที่ดึงมาถูก domain จริง ก่อนบันทึกลง `book-list.md`

## Naiin

- **หน้าสินค้า**: `https://www.naiin.com/product/detail/<product-id>` เช่น `https://www.naiin.com/product/detail/620720` — `<product-id>` เป็นตัวเลขล้วน
- **รูปปก**: อยู่ใน CDN `storage.naiin.com` รูปแบบ `https://storage.naiin.com/system/application/bookstore/resource/product/<YYYYMM>/<product-id>/<sku>_front_XXL.jpg?v=<timestamp>` — ดึงจาก `<meta property="og:image">` ในหน้า HTML จะได้ URL ตัวเต็มพร้อม query string ตรงตัว ไม่ต้องประกอบเอง
- **ผู้แต่ง / จำนวนหน้า**: อยู่ในตาราง "รายละเอียดสินค้า" ใต้ชื่อหนังสือ มักมีป้าย "ผู้แต่ง" และ "จำนวนหน้า" ตรงตัว — ถ้าเจอ "จำนวนหน้าโดยประมาณ" ให้ใช้ตัวเลขนั้นได้ แต่ควรตัดคำว่า "โดยประมาณ" ออกเหลือแค่ตัวเลข

## SE-ED

- **หน้าสินค้า**: โดเมนหลักคือ `se-ed.com` (บางครั้งอาจเจอ redirect จาก `se-ed.co.th` ซึ่งเป็นเว็บเดียวกัน ใช้ URL ปลายทางหลัง redirect เสมอ)
- **รูปปก**: ดึงจาก `<meta property="og:image">` เช่นเดียวกับ Naiin — SE-ED เสิร์ฟรูปจาก CDN ของตัวเองซึ่งโดเมนอาจเปลี่ยนได้ตามช่วงเวลา จึงไม่ hardcode รูปแบบ URL ตายตัวไว้ ให้ยึดหลัก "ดึงจาก og:image ของหน้าสินค้าจริงเสมอ" แทนการจำโดเมน CDN
- **ผู้แต่ง / จำนวนหน้า**: อยู่ในส่วน spec ใต้ชื่อหนังสือ ป้ายที่ใช้บ่อยคือ "ผู้เขียน" และ "จำนวนหน้า"

## หลักการตรวจสอบก่อนบันทึกทุกครั้ง

1. ลิงก์หนังสือ (`hostname` ของ URL) ต้องมี `naiin.com` หรือ `se-ed.com`/`se-ed.co.th` อยู่จริง — ถ้าผลค้นหาพาไปที่มาร์เก็ตเพลสอื่น (เช่น Shopee, Lazada) ที่ขายผ่านร้าน SE-ED/Naiin แต่ URL ไม่ใช่โดเมนของร้านเอง ให้ถือว่าไม่นับ ต้องหาให้เจอหน้าสินค้าโดยตรงบนเว็บร้านเท่านั้น
2. รูปปกต้องเป็น URL รูปภาพตรง (ลงท้ายด้วยนามสกุลไฟล์ภาพหรือมี query string ของรูป) ไม่ใช่ URL หน้าเว็บ HTML — เอาจาก `og:image` เป็นหลักเพราะเป็น URL ที่เว็บนั้นตั้งใจให้ใช้แสดงตัวอย่างหนังสืออยู่แล้ว
3. ถ้า `WebFetch` หน้าสินค้าไม่สำเร็จ (เว็บบล็อก bot, timeout) ให้ลองอีกครั้งด้วย query ที่เจาะจงขึ้น ถ้ายังไม่ได้ ให้แจ้งผู้ใช้ตรงๆ ว่าเข้าหน้าเว็บไม่ได้ แล้วถามว่าจะให้บันทึกแบบไม่มีลิงก์/รูปปกไปก่อนหรือลองแหล่งอื่น

**หมายเหตุเรื่อง Bitly:** การตรวจสอบ hostname ข้างต้นทำกับ URL เต็มจาก SE-ED/Naiin เท่านั้น ก่อนที่จะย่อ URL ด้วย Bitly — ต้องตรวจสอบให้ผ่านตามหลักการนี้ก่อนเสมอ แล้วค่อยเรียก Bitly ย่อทีหลังตามขั้นตอนใน SKILL.md ห้ามย่อ URL ที่ยังไม่ผ่านการตรวจสอบ

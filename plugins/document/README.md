# 🎉 document

Plugin for **Thai document work** — checks and drafts official government correspondence to the Thai Secretariat Regulations, and blinds sensitive data through pseudonymization.

### ⭐ Skills

| Skill | วัตถุประสงค์ |
|---|---|
| `saraban` | ตรวจสอบ ปรับปรุง และร่างเอกสารราชการไทยให้ถูกต้องตามระเบียบสารบรรณ พ.ศ. ๒๕๒๖ และฉบับแก้ไข (ฉบับที่ ๒–๔) ครอบคลุมหนังสือภายนอก บันทึกข้อความ ประกาศ คำสั่ง หนังสือประทับตรา หนังสือเวียน และงานสารบรรณอิเล็กทรอนิกส์ |
| `blind` | แทนที่ข้อมูล sensitive ด้วยข้อมูลสมมติที่ดูสมจริง (pseudonymization) — รักษารูปแบบและโครงสร้างเดิมไว้ ย้อนรอยกลับไม่ได้ รองรับทั้งข้อความทั่วไป เอกสารราชการ ตาราง Excel/CSV, PPTX และรายงานการเงิน |

### 🏆 Usage

```
/saraban <เอกสารราชการที่ต้องการตรวจ หรือเรื่องที่ต้องการร่าง>
/blind <ข้อความหรือเอกสารที่ต้องการซ่อนข้อมูล>
```

### 💎 ระดับการ blind

`blind` ถามระดับก่อนเสมอ เพราะการซ่อนมากเกินไปทำให้เอกสารอ่านไม่รู้เรื่อง ส่วนซ่อนน้อยเกินไปก็ยังระบุตัวตนได้

| ระดับ | เปลี่ยนอะไร |
|---|---|
| `Light` | ชื่อบุคคล, เบอร์โทร, อีเมล, เลขบัตรประชาชน/รหัสส่วนตัว |
| `Standard` *(default)* | ทุกอย่างใน Light + ชื่อหน่วยงานเฉพาะ, URL/โดเมน, ที่อยู่จริง, เลขที่หนังสือ, ชื่อโครงการ/ระบบเฉพาะ |
| `Full` | ทุกอย่างใน Standard + วันที่, ตัวเลขการเงิน, ตำแหน่งงาน |

### 💎 saraban vs blind

| ด้าน | `/saraban` | `/blind` |
|---|---|---|
| เป้าหมาย | ทำให้เอกสาร **ถูกระเบียบ** | ทำให้เอกสาร **แชร์ได้อย่างปลอดภัย** |
| Input | ร่างหนังสือ หรือเรื่องที่ต้องการเขียน | เอกสารที่มีข้อมูลจริงอยู่ |
| Output | เอกสารที่แก้ให้ตรงระเบียบ + จุดที่ผิดและเหตุผล | เอกสารหน้าตาเดิม แต่ข้อมูลถูกแทนด้วยของสมมติ |
| ใช้เมื่อ | ก่อนส่งหนังสือออก | ก่อนส่งเอกสารให้คนนอก หรือใช้เป็นตัวอย่าง |

วิธีถอดรหัสไฟล์นี้ (How to decrypt)
=====================================

ไฟล์ "__ARCHIVE_NAME__" ถูกเข้ารหัสด้วย GPG (OpenPGP) แบบ symmetric AES-256
ต้องใช้ passphrase ที่ผู้ส่งให้มาแยกต่างหาก (คนละช่องทางจากไฟล์นี้) เท่านั้นจึงจะถอดรหัสได้
ไม่ต้องสร้างหรือแลกเปลี่ยน key ใดๆ ทั้งสิ้น เพราะเป็นการเข้ารหัสแบบ passphrase (symmetric) ล้วนๆ

ไฟล์นี้ (คำแนะนำ) ไม่มีข้อมูลลับอยู่ในตัวเอง — ส่งไปพร้อมกับไฟล์ archive ได้ตามปกติ
มีแค่ "passphrase" เท่านั้นที่ต้องส่งแยกช่องทาง

---

ขั้นตอนที่ 1 — ตรวจสอบว่ามี gpg ในเครื่องหรือยัง
---------------------------------------------------

Windows (เปิด PowerShell):
    Get-Command gpg -ErrorAction SilentlyContinue

macOS / Linux (เปิด Terminal):
    command -v gpg

ถ้าไม่พบ ให้ติดตั้งก่อนตามระบบปฏิบัติการของคุณ:

  Windows              winget install GnuPG.Gpg4win
  macOS                brew install gnupg
                        (ถ้ายังไม่มี Homebrew ให้ติดตั้งจาก https://brew.sh ก่อน)
  Linux (Debian/Ubuntu) sudo apt install -y gnupg
  Linux (Fedora)        sudo dnf install -y gnupg2
  Linux (Arch)          sudo pacman -S gnupg

ขั้นตอนที่ 2 — ถอดรหัสไฟล์
---------------------------------------------------

เปิด Terminal/PowerShell ในโฟลเดอร์ที่มีไฟล์ "__ARCHIVE_NAME__" แล้วรัน:

    gpg --output __DECRYPTED_NAME__ --decrypt __ARCHIVE_NAME__

โปรแกรมจะถามหา passphrase — ใส่ passphrase ที่ได้รับจากผู้ส่ง (ผ่านอีกช่องทางหนึ่ง) แล้วกด Enter

ขั้นตอนที่ 3 — แตกไฟล์ archive
---------------------------------------------------

หลัง decrypt สำเร็จ จะได้ไฟล์ "__DECRYPTED_NAME__" ซึ่งเป็น tar.gz — แตกไฟล์ด้วยคำสั่งเดียวกันได้ทั้ง
Windows (มี tar มาให้ตั้งแต่ Windows 10 build 1803 ขึ้นไป), macOS และ Linux:

    tar -xzf __DECRYPTED_NAME__

จะได้โฟลเดอร์เนื้อหาต้นฉบับกลับมาครบตามที่ผู้ส่งเตรียมไว้

---

หมายเหตุด้านความปลอดภัย
---------------------------------------------------
- อย่าพิมพ์หรือส่งต่อ passphrase ในแชทหรืออีเมลเดียวกับไฟล์นี้ — ให้เก็บไว้คนละช่องทางเสมอ
- หลังถอดรหัสและใช้งานเสร็จ แนะนำให้ลบไฟล์ "__ARCHIVE_NAME__" และ passphrase ที่ได้รับออกจากเครื่อง
  หรือย้ายไปเก็บใน password manager แทนการเก็บเป็นไฟล์ข้อความไว้เฉยๆ

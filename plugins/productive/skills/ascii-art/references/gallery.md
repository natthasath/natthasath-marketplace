## สูตรผสมตามโอกาสใช้งาน

| โอกาส | คำสั่ง | ทำไม |
|---|---|---|
| Header ใน README.md | `--mode figlet --font standard --color none` | GitHub ไม่ render ANSI — สีจะกลายเป็นขยะ `[38;2;...m` เต็มไปหมด และ `standard` ใช้แค่ ASCII ล้วนจึงไม่พังบนฟอนต์ที่ผู้อ่านใช้ |
| Splash screen ของ CLI | `--mode figlet --font ansi_shadow --color cyan` | บล็อกทึบอ่านชัดในเทอร์มินัลทุกธีม สีเดียวดูสะอาดกว่า rainbow เมื่อขึ้นทุกครั้งที่รัน |
| MOTD / banner ตอน SSH เข้าเครื่อง | `--mode toilet --font pagga --border rounded --color matrix` | `pagga` เตี้ยแค่ 3 บรรทัด ไม่กินพื้นที่จอตอน login |
| แจ้งผลลัพธ์ build/test | `--mode box --border bold --color green` (หรือ `red` ถ้าพัง) | กรอบตัดบรรทัดยาวให้เอง และสีสื่อสถานะได้ทันทีโดยไม่ต้องอ่าน |
| ประกาศเวอร์ชันใหม่ / release | `--mode figlet --font colossal --color gold` | ตัวใหญ่เต็มจอ เหมาะกับข้อความสั้นๆ อย่างเลขเวอร์ชัน |
| ข้อความเตือน / error ที่ต้องเห็นแน่ๆ | `--mode figlet --font bloody --color fire` | หน้าตาดิบและสีร้อน แยกจาก log ปกติได้ทันที |
| มุกในสคริปต์ / commit hook | `--mode cowsay --character tux` | สั้น เบา และตัดบรรทัดให้เอง |
| ต้อนรับ / ข้อความเป็นมิตร | `--mode figlet --font script --color magenta` | ลายมือเขียนหวัด ดูไม่เป็นทางการ |
| โลโก้ → ASCII สำหรับ README | `--mode braille --threshold 128 --width 70` | Braille ให้ขอบคมกว่า jp2a มาก และเป็น text ล้วนจึงแปะใน markdown ได้ |
| รูปถ่าย → โชว์ในเทอร์มินัล | `--mode chafa --width 60` | สีจริง 24-bit ใกล้เคียงต้นฉบับที่สุด |
| รูปถ่าย → เอาไปแปะเป็น text | `--mode jp2a --ramp detailed --width 100` | ramp 70 ระดับไล่เฉดได้เนียนพอที่จะดูออกว่าเป็นรูปอะไร |

## ชุดสี

| ชื่อ | หน้าตา | ใช้เมื่อ |
|---|---|---|
| `none` | ASCII ล้วน | จะเอาไปแปะ README, code comment, ไฟล์ text — **ค่าเริ่มต้นที่ปลอดภัยที่สุด** |
| `rainbow` | ไล่สีรุ้งแนวทแยง | อยากได้ความสนุก ฉูดฉาด (แบบ lolcat) |
| `pride` | แถบสีรุ้ง 6 ชั้นแนวนอน | ฟิลเตอร์ `gay` ของ toilet — เป็นแถบชัดเจนกว่า rainbow |
| `metal` | ขาว → เทาฟ้า → น้ำเงินเข้ม | ดูแข็ง เป็นทางการ (ฟิลเตอร์ `metal` ของ toilet) |
| `fire` | เหลือง → ส้ม → แดง (สว่างด้านบน) | error, คำเตือน, ธีมร้อน |
| `ocean` | ฟ้าอ่อน → น้ำเงินเข้ม | เย็น สงบ |
| `matrix` | เขียวสว่าง → เขียวเข้ม | ธีม hacker/terminal |
| `gold` | ทองอำพัน | release, รางวัล, ของพรีเมียม |
| `red` `green` `yellow` `blue` `magenta` `cyan` `white` | สีเดียวล้วน | สื่อสถานะ (เขียว = ผ่าน, แดง = พัง) — อ่านง่ายกว่า gradient เมื่อขึ้นซ้ำๆ |
| `image` | ดึงสีจริงจากรูปมาใส่ตัวอักษร | **เฉพาะโหมด `jp2a`** — ได้ทั้งรูปทรงแบบ ASCII และสีจริง |

## เลือกโหมดรูปยังไง

| | `jp2a` | `chafa` | `braille` |
|---|---|---|---|
| ผลลัพธ์เป็น | ตัวอักษร ASCII | บล็อก `▀` + สี ANSI | อักขระ Braille `⣿` |
| สี | ได้ ถ้าใส่ `--color image` | สีจริง 24-bit เสมอ | ขาวดำ (ใส่ `--color` ทับได้) |
| ความละเอียดต่อ 1 ตัวอักษร | 1 พิกเซล | 2 พิกเซล (แนวตั้ง) | 8 พิกเซล (2×4) |
| แปะใน README ได้ไหม | ได้ (ถ้า `--color none`) | **ไม่ได้** — เป็น ANSI ล้วน | ได้ |
| ขนาด output ที่ width 80 | ~2 KB | ~27 KB | ~6 KB |
| เหมาะกับ | รูปทั่วไป, เอาไปแปะที่อื่น | โชว์ในเทอร์มินัลให้สวยที่สุด | โลโก้, ภาพลายเส้น, ภาพคมชัด |

**เคล็ดลับ**

- รูปที่มี contrast ต่ำ (ภาพหมอก, ภาพโทนเดียว) → `--ramp detailed` ให้ 70 ระดับ แทน `classic` ที่มี 10
- พื้นหลังรูปเป็นสีอ่อนแต่เทอร์มินัลเป็นธีมมืด → `--invert`
- `braille` กับโลโก้หรือภาพลายเส้น → ใส่ `--threshold 128` ไม่งั้น dithering จะทำให้พื้นเรียบ
  กลายเป็นจุดกระจาย ค่า threshold ต่ำ = ติดขาวมากขึ้น, สูง = ติดดำมากขึ้น
- `chafa` ที่ width เกิน 100 จะได้ output หลักแสน byte — ถ้าไม่ได้ต้องการรายละเอียดขนาดนั้น
  ใช้ 60–80 พอ

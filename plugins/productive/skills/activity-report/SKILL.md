# Activity Report Summarizer

ช่วยผู้ใช้สรุปความคืบหน้าของกิจกรรมในแผนการปฏิบัติงานประจำปีของสำนัก โดยถามคำถามตามกรอบ 5W แล้วเรียบเรียงออกมาเป็น 1 paragraph ภาษาทางการที่ครอบคลุมทุกมิติ ปฏิบัติตามกฎทุกข้อด้านล่างอย่างเคร่งครัด

อ่าน `references/5w-report.md` เพื่อดูกรอบ 5W เต็ม พร้อมคำถามแนะนำและโครงสร้าง paragraph

## Core Rules (Non-negotiable)

1. **ต้องได้ข้อมูลครบอย่างน้อย W2, W3, W5** ก่อนสรุปเป็น paragraph — ข้ามได้เฉพาะมิติที่ผู้ใช้ไม่มีข้อมูลจริงๆ
2. **ใช้ภาษาทางการแบบเอกสารราชการ** กระชับ อ่านแล้วเข้าใจภาพรวมได้ทันที
3. **ถ้าไม่มีข้อมูล W4 (ไม่มีอุปสรรค)** ให้ข้ามได้โดยไม่ต้องระบุว่า "ไม่มีอุปสรรค"
4. **สรุปต้องเป็น 1 paragraph ภาษาไทยเสมอ** เรียงตามลำดับ W1 → W2 → W3 → W4 → W5 ห้ามสลับลำดับ
5. **ตอบในรูปแบบ Artifact (markdown)** เพื่อให้ copy-paste นำไปใส่รายงานได้ทันที

## Workflow

### 1. รับรายละเอียดกิจกรรม
ถ้าผู้ใช้ยังไม่ได้บอก ให้ถามก่อน:
- ชื่อกิจกรรมคืออะไร
- วัตถุประสงค์หรือเป้าหมายของกิจกรรมนี้คืออะไร

รอให้ผู้ใช้ตอบก่อนดำเนินการขั้นต่อไป

### 2. ถามความคืบหน้าตามกรอบ 5W
ถามคำถามต่อไปนี้ให้ครบ — จะถามทีละข้อหรือรวมในครั้งเดียวก็ได้ตามธรรมชาติของการสนทนา:

| W | มิติ | คำถาม |
|---|------|-------|
| W1 | แผนคืออะไร | กิจกรรมนี้มีแผนการดำเนินงานอย่างไร (เป้าหมาย / ขั้นตอนที่วางไว้ / กรอบเวลา) |
| W2 | ทำอะไรไปแล้ว | ได้ดำเนินการอะไรไปแล้วบ้าง มีการเปลี่ยนแปลงจากแผนหรือไม่ |
| W3 | ได้อะไร | กิจกรรมที่แล้วเสร็จมีอะไรบ้าง ได้ผลอย่างไร สถานะ % ปัจจุบัน |
| W4 | ติดอะไร | กิจกรรมที่ยังไม่แล้วเสร็จ มีอุปสรรคหรือความล่าช้าหรือไม่ |
| W5 | ทำอะไรต่อ | ขั้นตอนถัดไปคืออะไร มีกำหนดเวลาหรือไม่ |

คำถามที่ผู้ใช้ไม่มีข้อมูลสามารถข้ามได้ แต่ควรได้ครบอย่างน้อย W2, W3, W5

### 3. Self-check แล้วสรุปเป็น 1 Paragraph
*หลักการ: ก่อนส่ง paragraph ให้ผู้ใช้ ให้ตรวจทานกับ Core Rules อีกรอบก่อนเสมอ — เป็นแค่อ่านทวนร่างตัวเอง ไม่มีต้นทุนสูง แต่ช่วยจับข้อผิดพลาดที่พลาดง่าย เช่น ลำดับ W สลับกัน หรือใส่ "ไม่มีอุปสรรค" ทั้งที่ควรข้าม*
- เมื่อได้ข้อมูลครบ ให้เรียบเรียงสรุปเป็น **1 paragraph ภาษาไทย** เรียงตามลำดับ W1 → W2 → W3 → W4 → W5
- ก่อนส่ง ให้ไล่เช็คร่างกับ Core Rules: ลำดับ W ถูกต้องไหม, ภาษาทางการไหม, W4 ที่ไม่มีข้อมูลถูกข้ามจริงไหม (ไม่ใช่เขียนว่า "ไม่มีอุปสรรค") — ถ้าไม่ผ่านข้อใด ให้แก้ก่อนส่ง
- ดูตัวอย่าง paragraph ที่ครบทุกมิติได้ใน `references/5w-report.md`

## Supporting files
- ใช้ `references/5w-report.md` เป็นข้อมูลอ้างอิงกรอบ 5W และตัวอย่าง paragraph
- ถ้าผู้ใช้แนบเอกสารแผนปฏิบัติงานหรือรายงานเดิมมา ให้ดึงข้อมูลจากนั้นก่อนถาม เพื่อลดคำถามซ้ำ

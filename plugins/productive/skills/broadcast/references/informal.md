# ระดับไม่เป็นทางการ (Informal)

ใช้สำหรับ Social Media (IG/X caption แบบ casual) และ community (Discord, กลุ่ม LINE/Facebook group)

## ลักษณะภาษา

- เป็นกันเองเต็มที่ ใช้สรรพนามแบบเพื่อน ("เรา", "พี่ๆน้องๆ") ภาษาพูดได้
- ใช้ emoji, GIF, คำสแลงได้ตามความเหมาะสมของ community นั้นๆ
- เน้นการพูดคุยสองทาง ไม่ใช่การประกาศทางเดียว
- โทนสนุก จริงใจ รู้สึกเป็นคนพูด ไม่ใช่องค์กรพูด

## โครงสร้าง

```
[เปิดด้วยคำทักทาย/อารมณ์ร่วม — ไม่ใช่ fact ทันที เช่น ทักทายแบบเพื่อน หรือตั้งคำถามเปิดเรื่อง]

[เล่าเรื่องแบบ storytelling สั้นๆ หรือเปิดบทสนทนาต่อจากคำถามข้างบน]

[CTA แบบเบาๆ ไม่ hard-sell เช่น "ใครเคยเจอบ้าง คอมเมนต์บอกเราหน่อย"]

emoji / #hashtag ที่สร้างความรู้สึกเป็น community
```

## เทคนิคตาม Intent (เมื่อใช้ใน Informal)

| Intent | เทคนิคเฉพาะ |
|---|---|
| Informative | เล่าแบบเพื่อนบอกเพื่อน ("เอาจริงๆ...", "มีเรื่องมาเล่า...") ไม่ใช่แจ้งแบบทางการ |
| Persuasive | ยกตัวอย่างจากประสบการณ์ตรงหรือ user-generated content มากกว่าเหตุผลเชิงนโยบาย |
| Promotional | ใช้ humor หรือ relatable reference ไม่พูดถึง benefit แบบตรงๆ เกินไป |
| Engagement | ใช้โพลล์/คำถามกระตุ้นคอมเมนต์ ยิ่ง specific ยิ่งได้ engagement |
| Awareness | ทำเป็น challenge หรือ hashtag campaign ที่คนเข้าร่วมได้ง่าย |
| Reputation | ใช้ behind-the-scenes content ให้เห็นความเป็นมนุษย์ขององค์กร |
| Relationship Building | shoutout สมาชิก community ที่มีส่วนร่วม ใช้โทนขอบคุณแบบเพื่อน |
| Advocacy | ชวนแชร์ต่อหรือติด hashtag แคมเปญ เน้นทำได้ง่ายใน 1 คลิก |
| Crisis Communication | **ระวังเป็นพิเศษ** — informal มักดูไม่จริงจังพอสำหรับเรื่องวิกฤต ถ้าผู้ใช้เลือก pairing นี้ ให้ถามยืนยันก่อนว่าตั้งใจจริงไหม หรือจะยกระดับเป็น Semi-formal/Formal แทน ถ้ายืนยัน ให้คงความจริงใจแต่ตัด emoji ที่ดูไม่เหมาะกับสถานการณ์ |
| Internal Communication | โทนทีมเล็กๆ กันเอง เหมาะกับ internal community channel ไม่ใช่ประกาศทางการ — ใช้ได้ดีกับทีมที่วัฒนธรรมองค์กร casual |

## ข้อควรระวัง

- Crisis Communication แทบไม่เหมาะกับ Informal — เตือนผู้ใช้ก่อนร่างตาม Core Rule 4 ใน SKILL.md เสมอ
- อย่าใช้สแลงหรือมีมที่อาจตีความผิดหรือดูไม่เหมาะกับภาพลักษณ์องค์กร ถ้าไม่แน่ใจให้ถามผู้ใช้
- ยังต้องรักษาข้อเท็จจริงให้ถูกต้อง แม้โทนจะเบาก็ไม่ใช่ข้อแก้ตัวให้ข้อมูลผิดพลาด

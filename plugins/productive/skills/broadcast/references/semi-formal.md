# ระดับกึ่งทางการ (Semi-formal)

ใช้สำหรับ Facebook Page, LINE OA broadcast, ข่าวกิจกรรม (event announcement บนเว็บ/จดหมายข่าวภายใน)

## ลักษณะภาษา

- เป็นมิตรแต่ยังสุภาพ ใช้ "เรา"/"ทีม [ชื่อองค์กร]" ได้
- ประโยคกระชับ อ่านง่าย ตัดคำฟุ่มเฟือย
- ใช้ emoji ได้บ้างเพื่อจุดสำคัญ (พอดี ไม่ถึงกับทุกบรรทัด) และใช้ hashtag ได้
- โทนอบอุ่น เข้าถึงได้ แต่ยังรักษาความน่าเชื่อถือขององค์กร

## โครงสร้าง

**Facebook Page Post:**

```
[Hook line — ประโยคแรกต้องดึงความสนใจใน 1-2 บรรทัด ก่อนโดน "ดูเพิ่มเติม" ตัด]

[เนื้อหาหลัก 2-3 ย่อหน้าสั้น อ่านจบไว]

[CTA ชัดเจน — กดลิงก์ / คอมเมนต์ / แชร์ / ลงทะเบียน]

#hashtag1 #hashtag2 #hashtag3
```

**LINE OA Broadcast** (คนอ่านบนมือถือ ต้องสั้นกว่า FB):

```
[คำทักทายสั้น]

[ใจความสำคัญ ไม่เกิน 3-4 บรรทัด]

[ปุ่ม/ลิงก์ CTA เดียว ชัดเจน]

— [ชื่อหน่วยงาน/ทีม]
```

**ข่าวกิจกรรม:**

```
[พาดหัวที่บอก benefit หรือ highlight ของกิจกรรม]

รายละเอียด: [วัน เวลา สถานที่ กลุ่มเป้าหมาย]

[ทำไมต้องมา/ร่วม — เหตุผลที่น่าสนใจ ไม่ใช่แค่ fact]

วิธีลงทะเบียน/เข้าร่วม: [ขั้นตอน]
```

## เทคนิคตาม Intent (เมื่อใช้ใน Semi-formal)

| Intent | เทคนิคเฉพาะ |
|---|---|
| Informative | สรุปประเด็นเป็น bullet สั้นๆ อ่านจบใน 10 วินาที |
| Persuasive | ใช้เหตุผล + ตัวอย่างที่จับต้องได้ (เคสจริง/ตัวเลขง่ายๆ) |
| Promotional | เน้น benefit เป็นข้อๆ ปิดด้วย CTA ที่กระตุ้นให้ลงมือทำทันที |
| Engagement | ตั้งคำถามปลายเปิด ชวนคอมเมนต์หรือแชร์ความเห็น |
| Awareness | แนะนำให้ใช้ภาพ/infographic ประกอบ เน้นสถิติที่จำง่าย 1-2 ตัว |
| Reputation | เล่าผ่านเสียงพนักงาน/ผู้ใช้จริง (testimonial) มากกว่าพูดถึงตัวเองตรงๆ |
| Relationship Building | แท็ก/ขอบคุณพาร์ทเนอร์ชัดเจน ใช้โทนอบอุ่น |
| Advocacy | ชวนร่วมลงชื่อ/แสดงจุดยืนผ่านการกระทำที่ทำได้จริง (ไม่ใช่แค่พูด) |
| Crisis Communication | ตอบไวแต่สุภาพ ยอมรับว่ากำลังตรวจสอบถ้ายังไม่มีข้อมูลครบ ชี้ไปช่องทางทางการสำหรับรายละเอียดเต็ม ไม่ปล่อยให้เงียบนาน — ถ้าสถานการณ์หนักจริง แนะนำผู้ใช้ให้พิจารณายกระดับเป็น Formal แทน |
| Internal Communication | โทนเป็นกันเองขึ้นกว่า Formal ใช้ "ทีมเรา" เน้นให้กำลังใจและสร้างความร่วมมือ |

## ข้อควรระวัง

- เนื้อหาต้องสั้นกว่า Formal มาก — คนอ่านบนมือถือ อย่าลากยาวเป็นย่อหน้าราชการ
- emoji/hashtag ใช้ได้แต่ต้องพอดี ใส่เยอะเกินจะดูไม่น่าเชื่อถือ
- ถ้าผู้ใช้ระบุ platform ที่มี character limit (เช่น LINE OA) ให้ปรับความยาวให้พอดีและแจ้งจำนวนตัวอักษร

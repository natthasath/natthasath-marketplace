# ระดับทางการ (Formal)

ใช้สำหรับหนังสือราชการ, ประกาศ/คำสั่ง, ข่าวแจก (press release) ทางการ, จดหมายเวียนภายในระดับองค์กร

## ลักษณะภาษา

- ใช้ภาษาราชการ/องค์กร เรียกตัวเองด้วยชื่อหน่วยงาน ("สำนักงาน...", "บริษัท...") ไม่ใช้ "เรา"
- ประโยคสมบูรณ์ ไม่ใช้คำย่อหรือภาษาพูด
- ห้ามใช้ emoji หรือ hashtag เด็ดขาด
- โทนเป็นกลาง สุภาพ นิ่ง มีน้ำหนัก (authoritative) ไม่ใช้คำเร้าอารมณ์

## โครงสร้าง

**หนังสือราชการ / ประกาศ:**

```
ที่ [เลขที่หนังสือ]                                    [ชื่อหน่วยงาน]
                                                        วันที่ [วัน เดือน ปี]
เรื่อง  [หัวข้อ]
เรียน   [ผู้รับ]

อ้างถึง / สิ่งที่ส่งมาด้วย (ถ้ามี)

[ย่อหน้าแรก: ระบุวัตถุประสงค์ของหนังสือให้ชัดเจนตั้งแต่ประโยคแรก]
[ย่อหน้าถัดไป: ขยายรายละเอียด เหตุผล หรือข้อกำหนด]
[ย่อหน้าสุดท้าย: สรุปสิ่งที่ผู้รับต้องทำ หรือผลที่จะเกิดขึ้น]

                                                        ลงชื่อ
                                                        [ชื่อ-ตำแหน่ง/หน่วยงาน]
```

**ข่าวประกาศ (press-release style):** ใช้โครงสร้าง inverted pyramid — ข้อเท็จจริงสำคัญสุดอยู่ประโยคแรก

```
[พาดหัวข่าว กระชับ บอกใจความสำคัญในประโยคเดียว]

[ย่อหน้าแรก: who/what/when/where/why ครบในย่อหน้าเดียว]
[ย่อหน้าถัดไป: รายละเอียดเพิ่มเติม บริบท เหตุผล]
[คำพูดอ้างอิง (quote) จากผู้บริหาร — ถ้ามี]

สอบถามรายละเอียดเพิ่มเติมที่ [ช่องทางติดต่อ]
```

## เทคนิคตาม Intent (เมื่อใช้ใน Formal)

| Intent | เทคนิคเฉพาะ |
|---|---|
| Informative | ระบุข้อเท็จจริง วันเวลา ตัวเลขให้ครบถ้วน ไม่ใช้คำคลุมเครือเช่น "เร็วๆนี้" |
| Persuasive | ใช้หลักฐานหรือเหตุผลเชิงนโยบาย/กฎระเบียบอ้างอิง ไม่ใช้คำเร้าอารมณ์ |
| Promotional | เน้นประโยชน์เชิงภารกิจ/นโยบาย มากกว่าการขาย หลีกเลี่ยงคำโฆษณาเกินจริง |
| Engagement | ระบุช่องทางที่เป็นทางการสำหรับแสดงความเห็น/ยื่นคำร้อง (ไม่ใช่ comment ใต้โพสต์) |
| Awareness | ใช้สถิติหรือข้อมูลอ้างอิงที่ตรวจสอบแหล่งที่มาได้ เน้นความน่าเชื่อถือ |
| Reputation | ย้ำพันธกิจ/มาตรฐานองค์กร อ้างอิงผลงานหรือการรับรองที่ตรวจสอบได้จริง |
| Relationship Building | กล่าวขอบคุณ/ยกย่องคู่ความร่วมมือ (MOU, หน่วยงานภาคี) อย่างเป็นทางการ |
| Advocacy | อ้างอิงกฎหมาย/มติ/มาตรฐานที่สนับสนุนประเด็น ระวังไม่ให้อ่านเป็นความเห็นส่วนตัว |
| Crisis Communication | **ต้องผ่านการตรวจทานจากผู้มีอำนาจ/ฝ่ายกฎหมายก่อนเผยแพร่เสมอ** ระบุเฉพาะข้อเท็จจริงที่ยืนยันแล้ว ไม่คาดเดา ปิดท้ายด้วยช่องทางติดต่อสำหรับข้อมูลเพิ่มเติม — นี่คือ pairing ที่เหมาะสมที่สุดของ Crisis Communication |
| Internal Communication | ใช้โทนทางการแต่กระชับกว่าหนังสือราชการทั่วไป ระบุ action ที่ผู้รับต้องทำให้ชัดพร้อม deadline |

## ข้อควรระวัง

- ห้ามใช้คำย่อ, emoji, หรือ hashtag ใน Formal เด็ดขาด
- ข้อมูล เลขที่หนังสือ วันที่ ผู้ลงนาม ต้องมาจากผู้ใช้เท่านั้น — ถ้าไม่มีให้ใส่ placeholder เช่น `[เลขที่หนังสือ]`
  และบอกผู้ใช้ตรงๆ ว่าต้องเติมเอง ห้ามแต่งขึ้นมาเอง

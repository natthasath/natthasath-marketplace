# 🎉 compliance

Plugin สำหรับ **ค้นและสรุปกฎหมาย ระเบียบ ข้อบังคับ** จากแหล่งทางการ — ครอบคลุมกฎหมาย/ระเบียบทั่วไป และระเบียบจัดซื้อจัดจ้างภาครัฐไทยโดยเฉพาะ

### 🤖 Agents

| Agent | Description |
|---|---|
| `regulation-researcher` | ค้นพระราชบัญญัติ พระราชกฤษฎีกา กฎกระทรวง ประกาศ และระเบียบราชการทั่วไป จากราชกิจจานุเบกษาและสำนักงานคณะกรรมการกฤษฎีกา พร้อมอ้างอิงมาตราและที่มาชัดเจน |
| `procurement-advisor` | อธิบายระเบียบ ขั้นตอน และวงเงินการจัดซื้อจัดจ้างภาครัฐ ตาม พ.ร.บ.จัดซื้อจัดจ้างฯ 2560 ระเบียบกระทรวงการคลัง และประกาศกรมบัญชีกลาง |

### 🏆 Usage

```
@compliance:regulation-researcher ช่วยหาว่ากฎหมายฉบับล่าสุดเกี่ยวกับ... คืออะไร
@compliance:procurement-advisor วิธีจัดซื้อจัดจ้างแบบเฉพาะเจาะจงใช้ได้เมื่อวงเงินเท่าไหร่
```

หรือขอให้ Claude ค้นกฎหมาย/ระเบียบตรงๆ ในบทสนทนา แล้วให้ตัดสินใจ delegate ไปยัง agent ที่เหมาะสมเอง

> [!NOTE]
> Agent ทั้งสองตัวอ้างอิงเฉพาะแหล่งทางการ (โดเมน `.go.th`, ราชกิจจานุเบกษา, กรมบัญชีกลาง) และปิดท้ายทุกคำตอบด้วยข้อความว่าไม่ใช่คำแนะนำทางกฎหมายที่มีผลผูกพัน — ควรตรวจสอบกับนักกฎหมายหรือหน่วยงานที่เกี่ยวข้องก่อนนำไปใช้จริง
